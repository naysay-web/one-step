                    1. Open Shortcuts. Tap +.
                    2. Add Find Health Samples. Pick Steps, today.
                    3. Add Calculate Statistics. Pick Sum.
                    4. Add Text: log=steps&count= + the Sum.
                    5. Add Copy to Clipboard.
                    6. Run it. Then tap Paste from Shortcut here.
